## 1. 개요 및 핵심 컨셉 (Overview & Core Concept)

- **서비스 정의**: 모가중학교 교직원들이 학교 현장에서 필요한 AI/수업자료/영상/업무자동화 아이디어를 제안하고, 공감(도토리) 투표로 우선순위를 결정하며, 실제 바이브 코딩으로 제작된 웹앱을 한곳에서 확인하고 실행할 수 있는 소통 플랫폼.
- **주요 대상**:
  - **모가중 교직원**: 로그인 없이도 닉네임과 함께 아이디어를 남기고 공감 투표 및 필터/검색.
  - **운영자 (`lbymeet12@gmail.com`)**: 부적절한 제안 삭제, 완성된 바이브코딩 웹앱 등록/수정/삭제, 전체 데이터 CSV 다운로드.

## 4. 단계별 구현 계획 (Phased Execution Steps)

### 1단계: 패키지 설치 및 환경 구성
- 필요한 아이콘 라이브러리(`lucide-react`)와 애니메이션(`motion`), 캔버스 축하 효과(`canvas-confetti`) 세팅.
- HTML 메타데이터(`index.html`, `metadata.json`)에 "모가중 바이브코딩 아이디어 마당" 반영.

### 2단계: Firebase Firestore & Google Auth 프로비저닝
- `set_up_firebase` 도구를 통한 Firestore 및 구글 로그인 프로비저닝.
- `firebase-blueprint.json` 및 `firestore.rules` 보안 규칙 작성 (관리자 `lbymeet12@gmail.com` 전용 수정/삭제 권한, 일반 사용자 생성/투표 권한).
- `handleFirestoreError` 에러 핸들러 및 Fallback Mock 데이터 연동.

### 3단계: 싸이월드 레트로 미니홈피 프레임워크 구축
- 더블 윈도우(외부 데스크톱 배경 + 내부 미니홈피 창) 컴포넌트.
- 좌측 사이드바: 미니룸(픽셀 그래픽/도트 감성), 프로필, 투데이 카운터, BGM 위젯, 실시간 랭킹 TOP 5.
- 우측 수직 탭 내비게이션 (홈/게시판, 모아보기, 바이브구현관, 관리자).

### 4단계: 핵심 4대 뷰(View) 컴포넌트 개발
1. **게시판 (HomeBoardView)**:
   - 교직원 환영 인트로 배너.
   - 아이디어 작성 폼 (닉네임, 카테고리 7종 드롭다운, 한 줄 제목, 최대 300자 설명, 실시간 글자수).
   - 작성 완료 시 도토리 파티클 피드백.
2. **모아보기 (AllIdeasView)**:
   - 최신순 / 좋아요순 정렬 토글.
   - 7개 카테고리 필터 + 키워드 검색바.
   - 카드 리스트 + 공감(도토리) 투표 버튼.
   - 페이지네이션 ([1], [2], [3] 페이지 분할).
3. **바이브코딩 구현관 (VibeProjectsView)**:
   - 바이브코딩으로 완성된 교직원용 웹앱 쇼케이스 카드.
   - 앱 제목, 설명, 반영된 원본 아이디어 태그, 바로가기 링크 버튼.
4. **관리자 대시보드 (AdminDashboard)**:
   - `lbymeet12@gmail.com` 구글 로그인 상태 감지.
   - 비인가 사용자 접근 차단 알림.
   - 아이디어 삭제/상태 변경 기능.
   - 새 바이브코딩 웹앱 추가/수정 모달.
   - **전체 의견 CSV 다운로드** (Excel 한글 깨짐 방지 UTF-8 BOM 적용).

### 5단계: 푸터 및 완성도 검증
- 푸터에 작고 깔끔한 운영자 로그인 버튼 배치.
- 전체 빌드(`compile_applet`) 및 무결성 검증.

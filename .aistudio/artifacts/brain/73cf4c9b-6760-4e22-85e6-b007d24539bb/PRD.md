# [PRD] 모가중 바이브코딩 아이디어 마당 (Cyworld Retro Minihompy Edition)

> **문서 상태**: 검토 요청 중 (Pending Confirmation)  
> **대상 사용자**: 모가중학교 교직원 및 운영자 (`lbymeet12@gmail.com`)  
> **버전**: v1.0.0  
> **작성일자**: 2026-10-19  

---

## 1. 프로젝트 개요 (Overview)

### 1.1 배경 및 목적
- 모가중학교 교직원들이 인공지능(AI), 수업자료 제작, 업무 자동화, 영상/이미지 생성 등 학교 현장에서 필요한 에듀테크/바이브코딩 아이디어를 부담 없이 제안하고 소통할 수 있는 전용 공간을 구축합니다.
- 친근하고 정겨운 **2000년대 싸이월드 미니홈피 감성의 레트로 UI**를 채택하여 참여율과 재미를 극대화합니다.
- 제안된 아이디어 중 실제 바이브 코딩으로 제작된 웹앱 결과물을 한눈에 볼 수 있는 전시관을 제공하여 아이디어가 실제 업무/수업 도구로 구현되는 효능감을 제공합니다.

### 1.2 핵심 목표 (Goals)
1. **자유로운 아이디어 수집**: 로그인 허들 없이 닉네임(미입력 시 익명)으로 빠르게 제안 등록.
2. **집단지성 공감 투표(Voting)**: 공감 버튼 및 실시간 랭킹 패널을 통해 교직원들의 우선순위와 관심사 파악.
3. **편리한 탐색**: 카테고리 필터링, 키워드 검색, 최신순/좋아요순 정렬, 페이지네이션 지원.
4. **결과물 아카이빙**: 제안이 실제 구현된 바이브 코딩 웹앱 링크 및 카드 전시.
5. **운영자 전용 통제권**: 특정 구글 계정(`lbymeet12@gmail.com`) 인증 기반 관리자 대시보드(의견 관리, 바이브코딩 앱 등록/수정/삭제, 데이터 CSV 추출).

## 3. UI/UX 디자인 컨셉: 2000년대 싸이월드 미니홈피 감성

1. **외관 구조 (Double-Window Layout)**:
   - 브라우저 중앙에 싸이월드 특유의 도트 그라디언트 배경(오렌지/스카이블루/그레이 톤)과 미니홈피 브라우저 창 배치.
   - 좌측 패널(프로필, 미니룸, BGM 플레이어, 오늘/총 방문자 카운터 `TODAY 42 | TOTAL 1982`, 일촌평/파도타기 감성 위젯).
   - 우측 메인 콘텐츠 패널 및 **우측 탭(Tab) 내비게이션** (`게시판(홈)`, `모아보기`, `바이브코딩 구현관`, `관리자`).
2. **디테일 & 텍스트 감성**:
   - 도토리 아이콘 공감 투표 ("도토리 주기 / 공감하기").
   - 폰트/스타일: 둥근 모서리와 1px 테두리, 레트로 윈도우 스타일 버튼, 주황색/하늘색 탭 포인트.
   - BGM 플레이어 위젯 (가상의 미니 플레이어, 2000년대 감성 트랙 리스트).
3. **푸터**:
   - 하단 구석에 조용히 배치된 운영자 로그인(`Admin Login`) 링크/버튼.

## 4. 메뉴별 상세 기능 요구사항

### 메뉴 1. 게시판 (홈: 인사말 & 아이디어 남기기)
- **환영 인트로**: "모가중 교직원 여러분의 반짝이는 에듀테크 & 바이브코딩 아이디어를 들려주세요!" 환영문 및 공지 안내.
- **아이디어 작성 폼**:
  - **닉네임**: 텍스트 입력 (선택 항목, 비워둘 시 `익명의 작성자` 자동 설정).
  - **카테고리**: 드롭다운 선택 (`AI활용`, `수업자료제작`, `이미지생성`, `영상제작`, `업무자동화`, `글쓰기`, `기타`).
  - **제목**: 한 줄 텍스트 입력 (필수).
  - **부연 설명**: 텍스트에어리어 (선택, 최대 300자 제한, 글자수 카운터 표시, placeholder: *"더 자세히 알려주시면 영상 제작에 큰 도움이 됩니다! (선택)"*).
  - **등록 버튼**: "아이디어 남기기 (도토리 적립)" 액션 버튼.
- **좋아요(Voting)**:
  - 각 제안글에 싸이월드 도토리/공감 버튼 배치 (중복 클릭 방지 세션/로컬 처리).
- **실시간 랭킹 패널**:
  - 가장 많은 좋아요(공감)를 획득한 TOP 5 인기 주제를 우측/상단에 실시간 하이라이트 노출.

### 메뉴 2. 모아보기 (전체 아이디어 보기 & 검색)
- **데이터 뷰**: 카드형 또는 다이어리/게시글 리스트 뷰.
- **정렬 옵션**: `최신순` / `좋아요(공감)순` 탭 정렬.
- **다면 필터링**:
  - 카테고리 칩/필터 (전체 및 7대 카테고리 다중/단일 토글).
  - 키워드 검색창 (제목, 부연설명, 닉네임 실시간 검색).
- **페이지네이션**: 글 수가 증가할 경우 하단 `[1, 2, 3...]` 번호형 페이지 이동 컨트롤 제공.

### 메뉴 3. 바이브코딩 구현관 (실제 제작 웹앱 아카이브)
- **결과물 카드 그리드**:
  - 교직원의 제안을 바탕으로 실제 바이브 코딩으로 제작된 웹앱을 카드 형태로 전시.
  - 구성: 썸네일/아이콘, 프로젝트 제목, 반영된 원본 제안 연계, 간략한 설명, 바로가기(`웹앱 실행하기`) 외부 링크 버튼.
- **운영자 전용 제어**:
  - 운영자 로그인 시에만 카드마다 [수정], [삭제] 버튼 및 [새 바이브코딩 앱 등록] 모달 버튼 노출.

### 메뉴 4. 관리자 대시보드 & 권한 관리
- **인증 (Authentication)**:
  - 구글 로그인 연동 (`lbymeet12@gmail.com` 계정에게만 즉시 운영자 권한 자동 부여).
  - 일반 교직원이 로그인할 경우 "운영자 권한이 없습니다" 친절한 안내 제공.
  - 로그인 버튼은 페이지 하단 푸터에 미니멀하게 배치.
- **의견 관리 (Moderation)**:
  - 등록된 모든 아이디어 목록 테이블.
  - 불필요/부적절한 의견 즉각 삭제 기능.
- **바이브코딩 연계 관리**:
  - 교직원 의견을 바탕으로 새 바이브코딩 결과물 등록, 수정, 삭제.
- **데이터 백업 / CSV 다운로드**:
  - 전체 제안 목록을 CSV 파일로 즉시 다운로드 (열 구성: `등록일시`, `카테고리`, `제목`, `부연설명`, `작성자(닉네임)`, `좋아요 수`, `바이브코딩 반영여부`).

## 5. 데이터 구조 정의 (Data Schema)

### Collection: `ideas` (제안글)
```typescript
interface Idea {
  id: string;
  nickname: string; // 기본값: "익명의 작성자"
  category: 'AI활용' | '수업자료제작' | '이미지생성' | '영상제작' | '업무자동화' | '글쓰기' | '기타';
  title: string;
  description?: string; // 최대 300자
  likesCount: number;
  likedUserIps?: string[];
  createdAt: number; // 타임스탬프
  status: 'pending' | 'in_progress' | 'completed'; // 바이브코딩 구현 상태
  vibeAppId?: string; // 연계된 완성 웹앱 ID
}
```

### Collection: `vibe_projects` (구현된 바이브코딩 앱)
```typescript
interface VibeProject {
  id: string;
  title: string;
  description: string;
  appUrl: string;
  category: string;
  relatedIdeaId?: string;
  thumbnailUrl?: string;
  createdAt: number;
  authorEmail: string;
}
```
